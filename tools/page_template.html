Molecule ExplorerAn interactive dashboard for a 27,000-row toxicology screening database

During my years as a research scientist, our lab tested hundreds of chemicals on engineered cell lines that glow when a hormone receptor is switched on. The results lived in one huge Excel sheet. I wrote a Python app with pandas and Bokeh so anyone on the team could filter that sheet and see dose–response curves in a few clicks. This page explains how it works and lets you use it on the real example dataset from the repository. Part of these data was published in Garoche et al., 2021, Environ. Sci. Technol.

Inside one experiment

From 96 wells to one row of the database

Each plate tests two chemicals on one cell line: the first in rows A–D, the second in rows E–H, at 7 concentrations diluted 3.16-fold, in 4 replicate wells. The four wells of one dose are averaged into the moy value of one row in the lab sheet. Pick a test type, then hover a well to see what it holds and the row it ends up in.

How the app works

From spreadsheet to dashboard in five steps

The whole tool is one 260-line script, main.py, run with bokeh serve Molecule --show. Each step below quotes the code.

Step 1pandas

Load the lab sheet

Read the shared Excel database straight into a DataFrame, indexed by molecule.

df = pd.read_excel(path,
  sheet_name='Data',
  index_col='Molecule')
Step 2pandas

Aggregate replicates

One pivot table merges repeated runs: mean and standard deviation per molecule × cell line × mode × serum × dose.

pd.pivot_table(df, 'moy',
  ['Molecule','Cell_line',
   'Color','Mode','Serum',
   'ConcM'],
  aggfunc=[np.mean, np.std])
Step 3NumPy

Clean for plotting

Gap markers become NaN, doses become ordered labels, and error bounds are precomputed.

df2 = df2.replace(50, np.nan)
df2['sd_upper'] = mean + std
df2['sd_lower'] = mean - std
df2 = df2.round(3)
Step 4Bokeh

Filter with boolean masks

Each checkbox group keeps its own True/False mask. A row is shown only when all four masks agree.

sel = df2.loc[cl_selection
  & mol_selection
  & mode_selection
  & serum_selection]
source.data.update(...)
Step 5Bokeh + JS

Plot, inspect, export

Bars and lines share one data source, with hover tooltips, SD whiskers, a data table and a CSV download written in JavaScript.

p1.vbar(top='mean_moy', ...)
p2.line(...); p2.circle(...)
Whisker(lower=..., upper=...)
Button(label='Download',
  callback=CustomJS(...))

What this project shows

Skills behind the tool

Data wrangling

Reshaping 27k heterogeneous rows (mixed date formats, placeholder values, excluded runs) into a tidy aggregated table.

Reactive visualisation

Server-side callbacks that recompute the view from boolean masks, so a click never reloads the whole dataset.

Designing for users

Built for biologists, not programmers: a single launcher, checkboxes instead of code, and a one-click export for their own analyses.

Documentation habits

A step-by-step README, commented code and a written list of known limits, carried over from research practice.
