Data analysis & visualisation · case study

Molecule ExplorerAn interactive dashboard for a 27,000-row toxicology screening database

During my years as a research scientist, our lab tested hundreds of chemicals on engineered cell lines that glow when a hormone receptor is switched on. The results lived in one huge Excel sheet. I wrote a Python app with pandas and Bokeh so anyone on the team could filter that sheet and see dose–response curves in a few clicks. This page explains how it works and rebuilds it so you can use it here, on the real example dataset from the repository. Part of these data was published in Garoche et al., 2021, Environ. Sci. Technol.

The science in 2 minutes

What one number in the spreadsheet means

Each cell line glows when its receptor is switched on. Pick a test type to see what goes into the well and a real example curve from the dataset.

  • MoleculeThe chemical being tested: pesticides, bisphenols, PFAS, drugs and reference ligands. 179 in this file. The seven “blind study” samples are coded compounds from one anonymised study.
  • Cell lineA human HeLa cell line carrying the ligand-binding part of one receptor (PPARα, PPARγ or PXR) from one species, fused to a yeast GAL4 switch that drives the luciferase gene. The control cell line has the switch and the luciferase but no receptor: it should stay at 100 %, and a drop means fewer living cells.
  • SerumSerum feeds the cells, but its proteins (mainly albumin) also trap lipophilic chemicals such as TBBPA, so less of the dose reaches the receptor. Environmental chemicals were therefore often tested without serum: rosiglitazone, GW 3965 and TBBPA were 3 to 17 times more potent that way. The trade-off is that cells without serum are more fragile, so a lower signal can come from stressed cells rather than from the chemical.
  • ConcM · moyConcentration in mol/L, and the normalised luciferase activity at that dose: 100 % is the maximum response to the cell line’s reference agonist.

How the app works

From spreadsheet to dashboard in five steps

The whole tool is one 260-line script, main.py, run with bokeh serve Molecule --show. Each step below quotes the original code.

Step 1pandas

Load the lab sheet

Read the shared Excel database straight into a DataFrame, indexed by molecule.

df = pd.read_excel(path,
  sheet_name='Data',
  index_col='Molecule')
Step 2pandas

Aggregate replicates

One pivot table merges repeated runs: mean and standard deviation per molecule × cell line × mode × serum × dose.

pd.pivot_table(df, 'moy',
  ['Molecule','Cell_line',
   'Color','Mode','Serum',
   'ConcM'],
  aggfunc=[np.mean, np.std])
Step 3NumPy

Clean for plotting

Gap markers become NaN, doses become ordered labels, and error bounds are precomputed.

df2 = df2.replace(50, np.nan)
df2['sd_upper'] = mean + std
df2['sd_lower'] = mean - std
df2 = df2.round(3)
Step 4Bokeh

Filter with boolean masks

Each checkbox group keeps its own True/False mask. A row is shown only when all four masks agree.

sel = df2.loc[cl_selection
  & mol_selection
  & mode_selection
  & serum_selection]
source.data.update(...)

Plot, inspect, export

Bars and lines share one data source, with hover tooltips, SD whiskers, a data table and a CSV download written in JavaScript.

Which chemicals switched on which receptor?

Each column is one molecule, each row one cell line. Colour shows the strongest mean response across all tested doses (agonist mode, with serum): pale blue means tested but inactive, close to 0 %. Hatched cells were never tested in that condition. The top row, HG5LN, is the control line: it sits near 100 % by design and only falls when a dose kills the cells. Columns are sorted from most to least active. Click a cell to load it in the dashboard below.

Interactive dashboard

Explore the dose–response data

Same controls and logic as the Bokeh app: tick at least one box in each group and the charts, table and export update together. It opens on rosiglitazone, a reference PPARγ activator, across the four PPARγ cell lines. The Hill fit gives EC50 values of 26 nM (human), 16 nM (mouse) and 0.73 µM (Xenopus), in line with the 24 nM, 16 nM and 718 nM published in the 2021 paper.

What this project shows

Skills behind the tool

Data wrangling

Reshaping 27k heterogeneous rows (mixed date formats, placeholder values, excluded runs) into a tidy aggregated table.

Reactive visualisation

Server-side callbacks that recompute the view from boolean masks, so a click never reloads the whole dataset.

Designing for users

Built for biologists, not programmers: a single launcher, checkboxes instead of code, and a one-click export for their own analyses.

Documentation habits

A step-by-step README, commented code and a written list of known limits, carried over from research practice.
