Data analysis & visualisation · case study

Molecule ExplorerAn interactive dashboard for a 30,000-row toxicology screening database

During my years as a research scientist, our lab tested hundreds of chemicals on engineered cell lines that glow when a hormone receptor is switched on. The results lived in one huge Excel sheet. I wrote a Python app with pandas and Bokeh so anyone on the team could filter that sheet and see dose–response curves in a few clicks. This page explains how it works and rebuilds it so you can use it here, on the real example dataset from the repository.

The science in 30 seconds

What one number in the spreadsheet means

  • MoleculeThe chemical being tested: pesticides, bisphenols, PFAS, drugs and reference ligands. 179 in this file.
  • Cell lineA reporter cell line carrying one receptor (PPARα, PPARγ or PXR) from one species: human (h), mouse (m), zebrafish (zf) or Xenopus (x). HG5LN is the control line: it emits light whatever the receptor, so it should stay at 100 %. A drop on HG5LN means fewer living cells, a sign of toxicity at that dose.
  • ModeAgonist: does the chemical switch the receptor on? Antagonist: does it block a reference activator? A drop counts as a real antagonist effect only if HG5LN stays at 100 %; if HG5LN falls along the same curve, the cells are simply dying.
  • SerumWhether the culture medium contained serum during exposure (YES / NO). Proteins in serum can bind chemicals and change the response.
  • ConcM · moyConcentration in mol/L, and the normalised luciferase activity measured at that dose (mean of the wells in one run).

How the app works

From spreadsheet to dashboard in five steps

The whole tool is one 260-line script, main.py, run with bokeh serve Molecule --show. Each step below quotes the original code.

Step 1pandas

Load the lab sheet

Read the shared Excel database straight into a DataFrame, indexed by molecule.

df = pd.read_excel(path,
  sheet_name='Data',
  index_col='Molecule')
Step 2pandas

Aggregate replicates

One pivot table merges repeated runs: mean and standard deviation per molecule × cell line × mode × serum × dose.

pd.pivot_table(df, 'moy',
  ['Molecule','Cell_line',
   'Color','Mode','Serum',
   'ConcM'],
  aggfunc=[np.mean, np.std])
Step 3NumPy

Clean for plotting

Gap markers become NaN, doses become ordered labels, and error bounds are precomputed.

df2 = df2.replace(50, np.nan)
df2['sd_upper'] = mean + std
df2['sd_lower'] = mean - std
df2 = df2.round(3)
Step 4Bokeh

Filter with boolean masks

Each checkbox group keeps its own True/False mask. A row is shown only when all four masks agree.

sel = df2.loc[cl_selection
  & mol_selection
  & mode_selection
  & serum_selection]

Plot, inspect, export

Bars and lines share one data source, with hover tooltips, SD whiskers, a data table and a CSV download written in JavaScript.

What this project shows

Skills behind the tool

Data wrangling

Reshaping 30k heterogeneous rows (mixed date formats, placeholder values, excluded runs) into a tidy aggregated table.

Reactive visualisation

Server-side callbacks that recompute the view from boolean masks, so a click never reloads the whole dataset.

Designing for users

Built for biologists, not programmers: a single launcher, checkboxes instead of code, and a one-click export for their own analyses.

Documentation habits

A step-by-step README, commented code and a written list of known limits, carried over from research practice.
